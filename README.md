# gaitcode
Code for "Characterization of Wearable Gait Analysis Method in Different Walking Trajectories and Sensor Placements Conditions".

This IMU‑gait processing code is developed by our research group and corresponds to a manuscript currently under review.

Any academic use of this code, including training, validation, analysis and publication, **MUST cite our forthcoming manuscript**.
Commercial usage is strictly prohibited.

Citation information will be updated once the manuscript is accepted and published.
The commit timestamp of this repository serves as the priority record of this code.
